# aiscientist-mcp

MCP servers for the AiScientist tools, one package per server, plus a shared runtime. AiScientist,
Claude Code and any other MCP client use the same servers. The tools are not part of the
AiScientist deploy package.

| Server | Category | Package | Tools | Status |
| --- | --- | --- | --- | --- |
| `atlas-expression-exploration` | single-cell | `packages/atlas-expression-exploration` | resolve_genes, submit_query, query_status, get_summary, plot_dotplot, plot_violin, plot_featureplot, write_report, list_queries | 0.0.1 |

`servers.json` is the machine-readable index (generated by `scripts/index_servers.py`): servers,
categories, versions, entry points and tools. Servers sit flat under `packages/`; the category is
metadata (`[tool.aiscientist-mcp] category` in each server's `pyproject.toml`), with the same
names as the skills registry, so skills and servers can be grouped together.

## Layout

```
packages/common/        shared runtime: aiscientist_mcp.common (server factory, path checks, jobs, CLI client)
packages/<server>/      one MCP server: aiscientist_mcp.<server_name>, entry point <server>-mcp, tests/
containers/<server>/    Dockerfile of the server image (ghcr.io/<owner>/mcp-<server>:<version>)
template/server/        scaffold for a new server (scripts/new_server.py)
scripts/                index_servers.py, new_server.py
```

## Install (development)

```bash
mamba create -y -n aiscientist_mcp -c conda-forge python=3.13.18 scanpy=1.12.5 anndata=0.13.4 pyarrow=26.0.0 mcp=2.3.0 pytest ruff
conda activate aiscientist_mcp
pip install --no-deps --no-build-isolation -e packages/common -e packages/atlas-expression-exploration
python -m pytest packages/common/tests packages/atlas-expression-exploration/tests
```

## Use a server

The settings come from environment variables:
- **Shared, read by the job runner:** `AISCI_DATA_DIR`, `AISCI_EXECUTOR` (`slurm`|`local`),
  `AISCI_SLURM`, `AISCI_SLURM_FALLBACK`, `AISCI_JOB_PREFIX`.
- **Server-specific:** see the server's README.

Claude Code (stdio):

```bash
claude mcp add-json --scope project atlas-expression-exploration '{"type":"stdio","command":"atlas-expression-exploration-mcp","env":{"ATLAS_H5AD":"/path/to/atlas.h5ad","AISCI_DATA_DIR":"/path/to/data","AISCI_SLURM":"--partition=<partition> --account=<account> --cpus-per-task=4 --mem=300G --time=04:00:00"},"timeout":900000}'
```

Shell, with any server:

```bash
aiscientist-mcp --server atlas-expression-exploration-mcp tools
aiscientist-mcp --server atlas-expression-exploration-mcp call resolve_genes '{"genes": "LRAT,CRALBP"}'
```

## Releases

- Tag `<server>-vX.Y.Z` (or `common-vX.Y.Z`).
- CI then runs the server's tests and pushes `ghcr.io/<owner>/mcp-<server>:X.Y.Z`.
- Skills and AiScientist pin that image (`image: docker://ghcr.io/<owner>/mcp-<server>:X.Y.Z`) or the
  git tag (`pip install "git+https://github.com/<owner>/aiscientist-mcp@<server>-vX.Y.Z#subdirectory=packages/<server>"`).

See [CONTRIBUTING.md](CONTRIBUTING.md) for the conventions every server follows.
